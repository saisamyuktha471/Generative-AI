In Week 4, I compared three different tokenization methods using English, Telugu and Hindi sentences.

**How I did it:**

Used the Hugging Face Transformers library.

Compared BPE using GPT-2.

Compared WordPiece using Multilingual BERT.

Compared SentencePiece using XLM-R.

Displayed tokens, token IDs and token counts.

**Commands used:**

cd week-4

pip install -r requirements.txt

python tokenizer_comparison.py
