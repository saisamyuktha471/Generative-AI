In Week 1, I connected my Python program with Google's Gemini AI using an API key. I sent a prompt to Gemini and received an AI-generated response.

**How I did it:**

Created a Python file.

Stored the Gemini API key in a .env file.

Used the google-genai library to connect with Gemini.

Sent a question and displayed the response.

**Commands used:**

**cd week1-llm-call**
**pip install -r requirements.txt**
python main.py
